# CardputerZero 应用：走通"我写 → 云端编译 → 你装 → 你验"流程

这份说明只讲一件事：怎么把代码变成一个能装进机器的安装包。
这一版用的是**官方原样模板**（带两个演示页面），目的不是做应用，是先验证整条流水线通不通。

## 这条流水线长什么样

1. 我在本地写好代码（已完成）
2. 代码推到你的 GitHub 仓库
3. GitHub 自动在云端编译，产出 `.deb` 安装包（不用你装任何软件）
4. 你把安装包下载到电脑，传给机器装上
5. 你在机器上验收：菜单里出现图标、点开能看到界面

以后我写任何新应用，都是重复第 1 步到第 5 步，不用再来回踩屏幕、键盘的坑——
因为这一版用的是官方 LVGL 模板，屏幕和键盘都按官方规矩来。

## 需要你配合的一次性动作

这台电脑没有登录你的 GitHub（本机的 SSH 密钥是 Gitee 的）。
所以第一次推送，需要你在命令行登录一次 GitHub。只需一次，以后都自动。

### 第 1 步：建一个空仓库

1. 用浏览器打开 https://github.com/new
2. Repository name 填：`cz-app`
3. 选 **Public**（公有，免费；私有也行但要确认 Actions 免费额度）
4. **不要**勾选 "Add a README" 等任何选项（保持完全空仓库）
5. 点 Create repository

### 第 2 步：把这行登录命令跑一下

在你自己的电脑上，打开 PowerShell，粘贴下面这条，回车：

```
git credential-manager github login
```

会弹出一个浏览器窗口让你登录 GitHub，输入账号密码（或有二次验证就按提示），登录成功后回到命令行。

### 第 3 步：告诉我登录成功了

你在命令行看到类似 "authorized" / "signed in" 的字样，回我一句"登录好了"。
接下来**推送代码、触发编译、下载安装包**全部由我来做，你不用再动手，直到安装验收那一步。

## 我这边接下来的动作（你不用做）

- 把本地工程提交、推到你的 `cz-app` 仓库
- 云端编译开始后，盯着编译结果；如果报错，我改到通过为止
- 编译成功后，告诉你下载链接，并给你真机安装、验收步骤

## 为什么要这么绕

之前我们试过"纯手写代码直接出安装包"，连踩 4 个坑（屏幕口、画布、颜色、键盘）。
不是你操作的问题，是那条路本身要自己处理太多底层细节。
官方模板 + 云端编译是官方所有应用都在用的正规路子，稳、可复现，也是商店上架的必经之路。
