## 按键说明（这版和以前不一样，记一下）

**列表页**（打开后先看到这个）：
- `N` = 新建一条笔记
- `S` = 打开/编辑选中的笔记
- `D` = 删除选中的笔记
- `↑ / ↓`（或 w/x）= 上下选
- **长按 ESC** = 退出应用

**编辑页**（打字的地方）：
- 直接按字母/数字键 = 输入
- `Del`（删除键）= 退格删一个字
- `Enter` = 保存并返回列表
- `ESC` 短按 = 放弃这条，返回列表
- **长按 ESC** = 退出应用

## 验收步骤（6 步）

1. 菜单里出现 **Pocket Notes**，点开
2. 看到列表页，提示 `N new / S open / D delete`，底部显示 `Ready`
3. 按 `N` 进入编辑页，屏幕出现 `Writing note:`
4. 打 `TEST 123`，屏幕上跟着出现这行字
5. 按 `Enter` 保存，回到列表，看到 `1. > TEST 123`
6. **长按 ESC** 退出，再打开 App，`TEST 123` 还在

第 6 步能保留，就说明存盘成功——这是这次最想验证的。

## 已知限制（第一版）

- 只支持小写字母、数字和少数符号（`. , / - ; '`），不支持中文和大写
- 一条笔记最多约 480 个字符
- 如果打字发现某些键没反应或打出错的字符，把屏幕拍给我——那是键位映射要微调，改一处就好
